## 📌 대표 프로젝트

### [P01 · 가상 차량 Body Control SW 개발 및 검증](https://github.com/James-Recon40/P01_Virtual-Vehicle-Body-Control-SW)

차체 편의 기능(전조등 · 와이퍼 · 도어 잠금 · 계기판 경고)을 C로 구현하고, 웹 UI에서 블랙박스 테스트로 검증한 **5인 팀 프로젝트** (2026.10, 팀장)

<img src="https://raw.githubusercontent.com/James-Recon40/P01_Virtual-Vehicle-Body-Control-SW/main/docs/demo/VBC_%EC%8B%9C%EC%97%B0.gif" width="720" alt="웹 UI 시연">

| 내가 한 일 | 내용 |
|---|---|
| 개발 프로세스 총괄 | V-Model 단계 · 산출물 계획, 역할 분담, 브랜치 · 리뷰 규칙 |
| 요구사항 분석 | 분석 양식 설계, 팀과 21개 공동 분석, 공통 규칙 C1~C5 상세 분석 |
| SW 아키텍처 설계 | 모듈끼리 직접 통신하지 않고 모든 값이 Vehicle Controller를 거치는 구조 (AUTOSAR RTE 개념 차용) |
| 테스트케이스 작성 | 요구사항 21개 → 블랙박스 TC 42개 (경계값 · 결정 테이블 · 상태전이) |

| 결과 | |
|---|---|
| 요구사항 | **21 / 21 충족** · 추적표로 요구사항 ↔ TC ↔ 판정 연결 |
| 검증 중 발견 · 수정 | **13건** (문서 모순 · 테스트케이스 오류 · 시험 환경 · 프로세스) |
| 블랙박스 테스트 | 42 / 42 PASS · 증거 기록 CSV 43개 |

> 구현은 상세설계서를 기준으로 AI(Claude Code)가 작성했고, 팀이 빌드 · 리뷰 · 테스트로 검증했습니다.<br>
> 처음에는 요구사항 분석 없이 시작했다가 통합에 실패해 처음부터 다시 시작했습니다. 이 경험이 이 프로젝트에서 가장 크게 배운 점입니다.
